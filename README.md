Este repositório é dedicado ao armazenamento das listas de exercícios e suas respectivas resoluções exclusivamente em **Python**.

## ▶️ Como Executar

Como o projeto agora é focado no uso do **VS Code** e execução local, você precisará ter o Python 3 instalado na sua máquina.

1. **Clone este repositório:**
```bash
git clone [https://github.com/victorhugo1506/LAED.git](https://github.com/victorhugo1506/LAED.git)
```

2. **Navegue até a pasta da lista desejada:**
```bash
cd LAED/"Lista sobre For"
```

3. **Execute o arquivo Python pelo terminal:**
```bash
python questao_02.py
```

> **💡 Dica para o VS Code:** > Evite usar espaços e acentos nos nomes dos arquivos. Para facilitar a execução via terminal, renomeie seus arquivos para o padrão `questao_10.py`. Isso evita erros na hora de chamar o script pela linha de comando!
